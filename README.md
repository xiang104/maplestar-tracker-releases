# 楓星紀錄 MapleStar Tracker

給《楓星》（MapleStory Worlds 平台）玩家使用的 Windows 桌面記錄工具。用行事曆的方式記錄每天玩了多久、做了什麼、賺了多少楓幣與經驗、打到什麼寶物，並管理每週四重置的王表與週任務。

所有資料只存在你自己的電腦上，不需要註冊、不需要登入、不會上傳任何遊戲紀錄。

> 本工具為玩家自製的非官方工具，與 Nexon 及 MapleStory Worlds 官方無任何關係。
> 程式內建的王圖片版權屬於原權利人（Nexon 及原作者），僅供玩家辨識使用；若權利人要求，將立即移除。

## 下載與安裝

1. 到 [Releases](https://github.com/xiang104/maplestar-tracker-releases/releases/latest) 下載最新版的 `MapleStar Tracker_x.y.z_x64-setup.exe`。
2. 執行安裝檔。

**關於「Windows 已保護您的電腦」警告**：程式目前沒有購買 Windows 程式碼簽章憑證，第一次安裝時 Windows SmartScreen 可能會跳出警告。請點「其他資訊」→「仍要執行」即可安裝。

**系統需求**：Windows 10 / 11（64 位元）。程式需要 Microsoft WebView2，Windows 11 已內建；Windows 10 若沒有，安裝程式會自動處理。

## 自動更新

程式啟動時會檢查是否有新版本，有更新時在畫面上方提示，按「下載並安裝」即可更新，資料不受影響。

- 更新檢查只會連線到本頁的 GitHub Releases 下載版本資訊，**不會傳送任何遊戲紀錄或個人資料**。
- 不想讓程式自動連網：到「設定 → 關於與更新」取消「啟動時自動檢查更新」，之後可以手動按「檢查更新」。
- 更新檔都經過簽章驗證，程式只會安裝由開發者簽章的版本。

## 功能

- **行事曆主畫面**：每天的格子顯示遊玩時數、楓幣、打過的王與安排；週四重置線標在月曆上。
- **遊戲紀錄**：一鍵開始／結束計時，記錄內容類型、地圖、楓幣與經驗（自動算出獲得量）、掉落寶物；可補登過去的紀錄。
- **每週王表**：每個王（各難度分開）顯示本週已打／可打次數，勾選一下就記錄打完；可補填收益、經驗加成（自動換算基礎經驗）與掉寶。
- **打王安排**：在月曆選未來的日期再點王，就能安排那天要打的王與時段；同一週已打與已安排的次數一起計算。
- **內建王表與圖片**：一鍵載入預設的王（名稱、難度、每週次數與圖片）。
- **每週任務**：自訂週任務，每週自動顯示新的清單，舊週次保留為歷史。
- **多角色**：每個角色各自有王表、週任務與紀錄。
- **資料匯出／匯入**：一鍵備份，換電腦或重灌也不會遺失紀錄。

## 資料存放位置與備份

所有資料存在一個 SQLite 資料庫檔案中：

```
%APPDATA%\com.maplestar.tracker\
```

- 建議定期使用「設定 → 資料備份 → 匯出資料」備份。
- 匯入備份檔前，程式會自動把目前的資料備份到 `%APPDATA%\com.maplestar.tracker\backups\`。
- 解除安裝程式不會刪除你的資料。

## 關於遊戲安全

本工具**只使用手動輸入**，不會讀取遊戲記憶體、不會擷取遊戲畫面、不會自動操作遊戲，也不會修改任何遊戲檔案。這是刻意的設計：任何自動讀取遊戲資料的做法都可能違反 MapleStory Worlds 的使用條款並導致帳號被處分，本工具不會加入這類功能。
